# Archivarius_bot
Архивариус — Telegram-бот, который ловит скинутые ему фото и видео, спрашивает папку и название, а потом находит их за секунду.

Добавить файл:
Кидаешь фото или видео — бот подхватывает, спрашивает папку и название, сохраняет. Три вопроса, и файл на полке.

Удалить файл:
Два пути: по точному названию или через папку. С подтверждением — случайно ничего не пропадёт.

Папки:
Все папки со счётчиками файлов. Внутри — список; нажал на файл — бот отправил его обратно.

Поиск по названию:
Пишешь кусочек названия — бот находит совпадения по всем папкам и отправляет файл прямо в чат. «паста» — и карбонара у тебя.
